# Карточка товара «Ананасовый улун» — Teaboom.ru

Тестовое задание на позицию HTML/Frontend-верстальщика: верхняя часть карточки товара
[Ананасовый улун](https://teaboom.ru/product/ananasovij-ulun).

**Демо:** https://froid228.github.io/teaboom-product-card/

## Что сделано

- изображение, категория, название, артикул, выбор фасовки, цена, старая цена, бейдж скидки, кнопка «В корзину», короткое описание и характеристики;
- при выборе фасовки меняются цена, старая цена, артикул, процент скидки и выбранное состояние; старая цена и бейдж скрываются, если скидки нет;
- у кнопки «В корзину» есть обычное состояние, наведение (тёмный фон и жёлтый текст, как на teaboom.ru) и короткое состояние «Добавлено» после нажатия — реальная корзина не подключена;
- адаптив: desktop 1440 px, tablet 768 px, mobile 375 px (на мобильном — одна колонка, фасовки сеткой 2×2, кнопка на всю ширину);
- цвета и шрифты (Open Sans, Oswald) взяты из текущей темы сайта.

## Решения

- **Семантика:** `article` для карточки, `nav` + `ol` для хлебных крошек, `fieldset`/`legend` и `radio` для фасовок, `s` для старой цены, `dl` для характеристик.
- **Доступность:** фасовки — настоящие radio-кнопки, поэтому работают с клавиатуры (стрелки, Tab) и скринридерами; цена объявляется через `aria-live`; видимый фокус через `:focus-visible`.
- **Данные фасовок** хранятся в `data-`атрибутах radio-кнопок, а начальное состояние уже есть в HTML — страница корректно выглядит и до загрузки JS.
- **SCSS по БЭМ:** переменные и миксины брейкпоинтов в `_variables.scss`, по одному файлу на блок.
- **JS без фреймворков:** один модуль, цены форматируются через `Intl.NumberFormat` (`349,20 ₽`, `1 432 ₽`).

## Структура

```
index.html
images/                 изображение товара
scripts/product-card.js логика переключения фасовок и кнопки
styles/main.css         скомпилированный CSS (подключён в index.html)
styles/scss/            исходники SCSS
  _variables.scss       цвета, шрифты, брейкпоинты
  _base.scss            базовые стили
  _breadcrumbs.scss
  _product-card.scss
  _packs.scss           выбор фасовки
  _price.scss
  _button.scss
  _specs.scss           характеристики
```

## Запуск

Сборка не нужна: скомпилированный CSS лежит в репозитории. Достаточно открыть `index.html` в браузере
или запустить любой статический сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

### Пересборка стилей

```bash
npm install
npm run build   # один раз
npm run watch   # пересборка при изменениях
```
